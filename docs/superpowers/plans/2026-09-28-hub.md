# Splitwave Hub 구현 계획

**Spec:** `docs/superpowers/specs/2026-09-28-hub-design.md` (규칙·문구·형식의 단일 출처. 이 계획과 어긋나면 spec 이 우선)

**Goal:** 허브 실행파일 하나로 세 앱을 설치, 업데이트, 삭제, 실행한다. 유튜브 봇 차단 오류 문구도 고친다.

## Global Constraints

- Python 3.12. 테스트: `.venv/bin/python -m pytest <파일> -q` (저장소 루트에서).
- `hub/core.py` 는 표준 라이브러리만 import 한다.
- 화면·오류 문구는 한국어, 이모지 금지. 문구는 spec 의 표를 글자 그대로 쓴다.
- 요청받은 파일만 만든다. 기존 코드는 고치지 않는다.
- 커밋하지 않는다 (조율자가 검증 후 커밋).
- 테스트와 selftest 는 오디오 스트림을 열지 않는다 (마이크·스피커 사용 금지).
- 테스트를 약하게 만들어 통과시키지 않는다.

## T2 hub/core.py

**Files:** Create `hub/__init__.py`(빈 파일), `hub/core.py`, `tests/test_hub_core.py`

**Produces (정확히 이 이름과 형):**

```python
REPO_URL = "https://github.com/Imtylerrrrrr/splitwave"
NOT_INSTALLED = "not_installed"; UP_TO_DATE = "up_to_date"; UPDATE_AVAILABLE = "update_available"

class HubError(Exception): ...            # str(e) 가 사용자에게 보일 한국어 문구

@dataclass(frozen=True)
class Part:    id: str; file: str; size: int; unpacked: int; sha256: str; content: str
@dataclass(frozen=True)
class HubFile: file: str; size: int; sha256: str
@dataclass(frozen=True)
class AppInfo: id: str; name: str; description: str; exe: str; parts: tuple[Part, ...]
@dataclass(frozen=True)
class Manifest:
    version: str; hub: HubFile | None; apps: tuple[AppInfo, ...]
    def app(self, app_id: str) -> AppInfo      # 없으면 HubError("목록에 없는 앱이에요.")
@dataclass(frozen=True)
class Status:  state: str; installed_version: str | None; download_size: int

def parse_manifest(data: bytes | str | dict) -> Manifest
def default_root() -> Path
def child_env() -> dict[str, str]
def check_final_url(url: str, https_only: bool) -> None      # 위반 시 HubError(네트워크 문구)

class Source:
    def __init__(self, base_url: str | None = None)
    https_only: bool                                          # base_url 이 None 일 때 True
    def manifest_url(self) -> str
    def asset_url(self, version: str, file: str) -> str

Progress = Callable[[int, int, str], None]                    # (받은 바이트, 전체 바이트, 파일 이름)

class Hub:
    def __init__(self, root: Path | None = None, source: Source | None = None)
    root: Path
    def log(self, msg: str) -> None                           # <root>/hub.log 에 시각과 함께 한 줄
    def fetch_manifest(self) -> Manifest
    def installed(self) -> dict[str, dict]                    # state["apps"] 의 복사본
    def status(self, app: AppInfo) -> Status
    def install(self, manifest: Manifest, app_id: str, progress: Progress | None = None) -> None
    def remove(self, app_id: str) -> None
    def is_running(self, app_id: str) -> bool
    def launch(self, app_id: str, args: Sequence[str] = ()) -> subprocess.Popen
    def hub_update_available(self, manifest: Manifest) -> bool
    def self_update(self, manifest: Manifest, progress: Progress | None = None) -> Path
    def cleanup_old_self(self) -> None
```

- 다운로드: `urllib.request`, User-Agent `splitwave-hub`, timeout 30 초, 64 KiB 씩 읽으며 sha256 계산과 progress 호출.
- progress 의 전체 바이트는 이번 작업에서 받을 모든 part 의 size 합, 받은 바이트는 누적값.
- `self_update` 는 새 실행파일 경로를 돌려준다. 띄우고 종료하는 것은 호출자 몫.

**Tests (tests/test_hub_core.py):** 픽스처가 tmp_path 에 합성 part 파일과 매니페스트를 만들고
`ThreadingHTTPServer(("127.0.0.1", 0))` 로 제공하며 요청 경로를 기록한다. `content` 는 spec 의 정의대로 테스트 헬퍼가 계산한다.

1. parse_manifest: 정상 1건, spec "검증 규칙" 위반마다 1건씩 (parametrize). schema 2 는 문구에 "업데이트" 포함.
2. Source: 운영 주소 두 개, `--base` 재정의 주소 두 개.
3. 새 설치: 파일 존재, state 기록, `downloads/` 비어 있음, status 가 UP_TO_DATE.
4. zip 이 아닌 part: 파일 이름 그대로 앱 폴더에 복사.
5. 업데이트: part 2개 중 하나만 바뀐 매니페스트 → 서버 요청 기록에 바뀐 part 만, 새 zip 에서 빠진 파일은 삭제, 안 바뀐 part 의 파일은 그대로.
6. 매니페스트에서 사라진 part: 그 파일들이 삭제되고 state 에서도 사라짐.
7. 설치된 파일을 하나 지우면 status 가 UPDATE_AVAILABLE, install 이 복구.
8. sha256 불일치, size 불일치: HubError(손상 문구), 앱 폴더에 아무것도 없음, `.part` 없음.
9. zip 경로 위반 4종(`../x`, `/abs`, `..\\x`, 심볼릭 링크 속성): HubError(경로 문구), 아무것도 풀리지 않음.
10. 삭제: 기록된 파일만 지움. 사용자가 넣은 파일이 있으면 그 파일과 앱 폴더는 남음. 없으면 앱 폴더 삭제.
11. 미설치 앱의 remove, launch: HubError(미설치 문구).
12. 공간 부족: `shutil.disk_usage` 를 monkeypatch → HubError, 문구에 필요한 MB.
13. 서버가 꺼져 있을 때 fetch_manifest: HubError(네트워크 문구).
14. state.json 이 깨져 있으면 빈 상태로 동작.
15. child_env: `_PYI_*`, `_MEIPASS2` 제거, `PYINSTALLER_RESET_ENVIRONMENT=1`.
16. launch: `subprocess.Popen` 을 monkeypatch 해 인자, cwd, env 확인.
17. hub_update_available: frozen 아님 → False. `sys.frozen`/`sys.executable` 을 monkeypatch 해 해시 같음 → False, 다름 → True.
18. self_update: `sys.executable` 을 임시 파일로 monkeypatch → 원래 경로에 새 내용, `.old` 에 옛 내용, `.new` 없음. cleanup_old_self 가 `.old` 삭제.
19. check_final_url: https_only 에서 http 주소는 HubError, https 는 통과, https_only 아니면 http 통과.

## T3 tools/make_manifest.py

**Files:** Create `tools/make_manifest.py`, `tools/apps.json`, `VERSION`, `tests/test_make_manifest.py`. `hub` 패키지를 import 하지 않는다.

**사용:** `python tools/make_manifest.py --version 1.1.0 --apps tools/apps.json --dir release`

**Produces:**

```python
def content_hash(path: str) -> str        # spec 의 content 정의
def unpacked_size(path: str) -> int
def part_files(path: str) -> list[str]    # zip 이면 디렉터리 제외 멤버 경로(\ 는 / 로), 아니면 [파일 이름]
def build_manifest(version: str, apps_def: dict, directory: str) -> dict
def write_sums(directory: str) -> None    # SHA256SUMS.txt: "<sha256>  <이름>" 이름순, 자기 자신 제외, manifest.json 포함
def main(argv: list[str] | None = None) -> int
```

- 실패는 한 줄 메시지 + 고치는 법으로 `SystemExit` (스택 트레이스 금지). 예: `make_manifest: missing release/splitwave.exe. Fix: download the CI artifact into the directory.`
- 검사: version 형식, 자산 파일 존재, 한 앱의 part 간 경로 중복 없음, `exe` 가 part 파일 목록에 존재.
- `manifest.json` 은 UTF-8, `ensure_ascii=False`, indent 2.
- 큰 파일(200 MB zip)도 메모리에 통째로 올리지 않는다 (1 MiB 씩 읽기).

**tools/apps.json:**

```json
{
  "hub": "splitwave-hub.exe",
  "apps": [
    {"id": "splitwave", "name": "Splitwave", "description": "유튜브 음원 다운로드와 키 조정",
     "exe": "splitwave.exe", "parts": [{"id": "app", "file": "splitwave.exe"}]},
    {"id": "splitwave-full", "name": "Splitwave + 스템 분리", "description": "다운로드, 키 조정, 악기별 분리",
     "exe": "splitwave-full/splitwave-full.exe", "parts": [{"id": "all", "file": "splitwave-full.zip"}]},
    {"id": "tempofollow", "name": "Tempo Follow (실험)", "description": "드럼 템포를 따라가며 곡을 재생",
     "exe": "tempofollow/tempofollow.exe", "parts": [{"id": "all", "file": "tempofollow.zip"}]}
  ]
}
```

**VERSION:** `1.1.0` 한 줄.

**Tests:** 합성 파일로 (1) content_hash 가 zip 재생성(다른 타임스탬프, 다른 멤버 순서)에도 같음, 내용이 1바이트 바뀌면 다름
(2) 일반 파일의 content == sha256 (3) build_manifest 결과의 필드와 값 (4) part 간 경로 중복 → SystemExit
(5) exe 가 목록에 없음 → SystemExit (6) 자산 없음 → SystemExit, 메시지에 `Fix:` (7) write_sums 형식과 자기 자신 제외
(8) 저장소의 `tools/apps.json` 이 읽히고 앱 id 3개.

## T4 tempofollow selftest

**Files:** Create `tempofollow/selftest.py`, `tempofollow_main.py`, `tests/test_tempofollow_selftest.py`. 기존 `tempofollow/*.py` 는 고치지 않는다.

`selftest() -> int` (0 = 정상, 실패 시 이유 한 줄을 stderr 에 쓰고 1):

1. `common.find_ffmpeg()` 가 없으면 실패.
2. 4초, 120 BPM 클릭 트랙(44.1 kHz 모노)을 numpy 로 만들어 임시 폴더에 16비트 WAV 로 저장 (`wave` 모듈).
3. `tempofollow.engine.decode` 로 읽어 길이가 4초의 ±1 % 안.
4. `tempofollow.tempo.estimate_bpm` 결과가 120 의 ±2 % 안.
5. `tempofollow.stretch.WSOLA` 로 비율 1.1 청크를 몇 번 뽑아 모두 유한값.
6. `tempofollow.tempo.TempoTracker` 에 클릭 트랙을 넣어 `bpm` 이 유한값.
7. `import sounddevice as sd; sd.query_devices()` 가 예외 없이 끝남 (장치 0개여도 정상). 스트림은 열지 않는다.
8. `selftest: tempofollow ok` 출력.

`tempofollow_main.py`: `--selftest` 면 `sys.exit(selftest())`, 아니면 `tempofollow.app.main()`. selftest 경로에서는 `tempofollow.app` 을 import 하지 않는다.

**Test:** ffmpeg 와 sounddevice 가 있으면 `selftest() == 0` 이고 출력에 `tempofollow ok`. 없으면 skip.

## T5 hub/cli.py, hub/app.py, hub_main.py

**Files:** Create `hub/cli.py`, `hub/app.py`, `hub_main.py`, `tests/test_hub_cli.py`. Modify `tests/test_no_emoji.py` (대상에 `hub/app.py`, `hub/cli.py`, `hub/core.py` 추가).

**Consumes:** T2 의 `hub.core` 공개 이름 전부.

- `hub/cli.py`: `main(argv: list[str] | None = None) -> int`, `selftest() -> int`. 명령과 종료 코드는 spec "명령줄".
  인자가 `cli` 도 `--selftest` 도 아니면 `hub.app.run(root, base)` 호출 (`hub.app` 은 그때 import).
- `hub/app.py`: `run(root: Path | None, base: str | None) -> None`, `class App(ctk.CTk)`. 화면은 spec "화면".
  테마·아이콘 적용은 `tempofollow/app.py` 와 같은 방식 (`common.resource_path`).
  문구를 만드는 순수 함수는 클래스 밖에 둔다: `fmt_mb(n: int) -> str`, `status_text(status: Status, latest: str | None, check_failed: bool) -> str`, `buttons_for(state: str) -> list[str]`.
- `hub_main.py`: `from hub.cli import main; sys.exit(main())`.

**Tests (tests/test_hub_cli.py):** 로컬 HTTP 서버 픽스처로 (1) `cli status` 출력 형식 (2) `cli install` 후 파일 존재, 종료 코드 0
(3) 없는 앱 install → 1 (4) `cli remove` (5) `cli run --wait -- a b` 가 Popen 인자와 종료 코드를 전달 (Popen monkeypatch)
(6) 사용법 오류 → 2 (7) `selftest() == 0` (8) `status_text`, `fmt_mb`, `buttons_for` 의 값이 spec 문구와 글자 그대로 같음.
화면 클래스는 테스트에서 만들지 않는다.
