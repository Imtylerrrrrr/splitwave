## 새로 생긴 것

- **빼고 듣기.** 스템 분리 탭에서 악기를 체크하면 그 악기만 뺀 음원을 따로 저장해요. 기타를 체크하면 `기타 제거.wav`, 베이스도 체크하면 `베이스 제거.wav` 가 같이 나와요.
  - 연습할 때 자기 파트만 빼고 틀어 놓는 용도예요. 분리는 한 번만 돌아서 시간이 더 걸리지 않아요.
  - `저장할 스템` 을 모두 끄고 `빼고 듣기` 만 체크해도 돼요.
  - 파일은 `<곡이름>_stems/` 폴더에 들어가서, 보관함과 Tempo Follow 목록에 `곡 제목 / 기타 제거` 로 바로 나와요. 키 조정도 같이 적용돼요.
- 뺀 음원의 품질은 분리 품질과 같아요. 기타를 뺀 음원에는 기타 소리가 조금 남을 수 있어요. 보컬·드럼은 더 깨끗해요.

## 업데이트 크기 (허브 사용 시)

| 앱 | 받는 크기 |
|---|---|
| Splitwave | 약 27 MB |
| Splitwave + 스템 분리 | 약 33 MB (앱 본체 묶음만. torch, 모델, 실행 환경은 그대로) |
| Tempo Follow (실험) | 약 32 MB |

허브 자체는 바뀌지 않았어요. 허브를 열고 `업데이트` 를 누르면 돼요. 처음이면 `splitwave-hub.exe` 하나만 받으세요.

## 확인한 것과 못 한 것

- 확인: 실제 분리 모델로 `기타 제거` 가 원본에서 기타 스템을 뺀 것과 같은지 테스트. 스템을 모두 끄고 빼고 듣기만 체크해도 시작되는지, 새 줄을 넣어도 창 아래 버튼이 잘리지 않는지 화면 테스트.
- 못 함: 실제 곡으로 사람이 들어 보는 확인, Windows 화면에서 사람이 눌러 보는 확인.
