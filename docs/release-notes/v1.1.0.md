## 새로 생긴 것

- **Splitwave Hub** (`splitwave-hub.exe`, 약 15 MB). 허브 하나만 받으면 앱을 버튼으로 설치, 업데이트, 삭제, 실행할 수 있어요.
  - 받은 파일은 허브가 해시를 자동으로 대조해요.
  - 설치 위치는 `%LOCALAPPDATA%\Splitwave`. 관리자 권한이 필요 없어요.
  - 풀 버전은 네 묶음으로 나눠 받아요. 업데이트 때는 바뀐 묶음만 받아서 보통 33 MB예요 (통째로는 209 MB).
- **Tempo Follow (실험)** 의 첫 Windows 빌드. 허브에서 설치할 수 있어요. 드럼을 마이크로 듣고 곡의 재생 속도를 맞춰요.

## 고친 것

- 유튜브가 인터넷 회선을 자동 프로그램으로 의심해 막았을 때, 영어 원문 대신 무슨 상황이고 어떻게 하면 되는지 한국어로 안내해요.
  이 차단은 프로그램 문제가 아니라서 새 버전으로도 풀리지 않아요. 다른 인터넷(휴대폰 핫스팟)으로 바꾸거나 몇 시간 뒤에 다시 시도하세요.

## 받는 법

| 파일 | 용도 |
|---|---|
| `splitwave-hub.exe` | **권장.** 허브. 이것만 받으면 돼요 |
| `splitwave.exe` | 허브 없이 직접: 다운로드 + 키 조정 |
| `splitwave-full.zip` | 허브 없이 직접: 스템 분리 포함. 압축을 풀고 폴더 안의 exe 실행 |
| `tempofollow.zip`, `splitwave-full-*.zip`, `manifest.json` | 허브가 받아 가는 파일. 직접 받을 필요 없어요 |
| `SHA256SUMS.txt` | 해시 대조용 |

처음 실행할 때 Windows 가 "알 수 없는 게시자" 경고를 띄우면 "추가 정보 → 실행"을 누르세요. 서명 인증서가 없어서 그래요.

## 확인한 것과 못 한 것

- 확인: GitHub 의 Windows 서버와 실제 Windows 11 PC(Defender 실시간 보호 켜짐)에서, 빌드된 허브로 세 앱을 설치하고 자체 점검을 실행하고 삭제. 백신 탐지 0건.
- 확인: 이전 빌드에서 이번 빌드로 업데이트할 때 앱 본체 묶음 하나만 받고, 결과가 새 빌드와 파일 단위로 같음.
- 못 함: 허브 화면을 Windows 에서 사람이 눌러 보는 확인, SmartScreen 경고창, Tempo Follow 의 실제 드럼·마이크 사용.
