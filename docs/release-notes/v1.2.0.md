## 새로 생긴 것

- **곡 보관함.** 받은 곡과 분리한 스템이 한 폴더(`저장 폴더/Splitwave`)에 모이고, 세 앱이 같은 보관함을 봐요.
  - **스템 분리**: `보관함에서 선택` 드롭다운에서 받아 둔 곡을 바로 골라요. 파일 선택 창에서 찾을 필요가 없어요.
  - **Tempo Follow**: `보관함` 드롭다운에서 곡이나 스템(예: `곡 제목 / 건반`)을 골라요.
  - **다운로드**: 이미 받은 링크를 다시 받으려 하면 알려 주고, 그래도 받을지 물어요.
- 예전에 저장 폴더에 바로 받아 둔 파일은 옮기지 않아요. 보관함 폴더에 직접 넣으면 목록에 나와요.

## 고친 것

- 허브가 릴리스마다 "허브 새 버전이 있어요"라고 하던 문제. 이제 허브 코드가 실제로 바뀐 릴리스에서만 안내해요.
  v1.1.0 허브를 쓰고 있다면 이번에 한 번 `허브 업데이트`를 눌러 주세요.

처음이면 `splitwave-hub.exe` 하나만 받으세요. 이미 허브가 있으면 허브를 열고 `업데이트`를 누르면 돼요.

## 확인한 것과 못 한 것

- 확인: GitHub 의 Windows 서버에서 빌드된 허브로 세 앱을 설치, 자체 점검 실행, 삭제.
- 확인: 실제 Windows 11 PC 에서 v1.1.0 설치 상태를 v1.2.0 으로 업데이트. 받은 묶음은 릴리스 페이지의 표와 같음.
- 못 함: 드롭다운과 허브 화면을 Windows 에서 사람이 눌러 보는 확인, 실제 유튜브 다운로드(시험한 회선이 유튜브에 막혀 있음), Tempo Follow 의 실제 드럼·마이크 사용.
