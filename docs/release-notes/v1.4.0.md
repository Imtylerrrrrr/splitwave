## 새로 생긴 것

- **체크한 것을 합친 파일도 저장.** 스템 분리 탭의 새 체크박스예요. 켜면 각각의 파일에 더해 `저장할 스템` 에서 고른 파트를 합친 파일(예: `드럼+기타.wav`)과 `빼고 듣기` 에서 고른 악기를 모두 뺀 파일(예: `보컬+기타 제거.wav`)이 같이 나와요. 드럼과 기타만 틀어 놓고 타이밍을 맞추는 식으로 쓰세요. 분리는 한 번만 돌아서 시간이 더 걸리지 않아요.
  - 하나만 고르면 합친 파일은 각각과 같아서 따로 만들지 않아요.
  - 보관함과 Tempo Follow 목록에는 `곡 제목 / 드럼+기타` 로 보여요. 키 조정도 같이 적용돼요.
- **같은 곡을 다시 돌릴 때 물어요.** 결과 폴더(`<곡이름>_stems`)에 이미 파일이 있으면 덮어쓸지, `<곡이름> (2)_stems` 같은 새 폴더에 저장할지, 그만둘지 물어요. 유튜브 링크는 받은 뒤에 제목을 알기 때문에 다운로드가 끝난 뒤에 물어요.

## 업데이트 크기 (허브 사용 시)

| 앱 | 받는 크기 |
|---|---|
| Splitwave | 약 27 MB |
| Splitwave + 스템 분리 | 약 33 MB (앱 본체 묶음만. torch, 모델, 실행 환경은 그대로) |
| Tempo Follow (실험) | 약 32 MB |

허브 자체는 바뀌지 않았어요. 허브를 열고 `업데이트` 를 누르면 돼요. 처음이면 `splitwave-hub.exe` 하나만 받으세요.

## 확인한 것과 못 한 것

- 확인: 실제 분리 모델로 `드럼+기타` 가 드럼과 기타 스템의 합과 같은지, `드럼+기타 제거` 가 원본에서 둘을 뺀 것과 같은지 테스트. 결과 폴더가 있을 때 예·아니오·취소 각각의 동작과 빈 폴더면 묻지 않는 것, 새 줄을 넣어도 창 아래 버튼이 잘리지 않는지 화면 테스트.
- 못 함: 실제 곡으로 사람이 들어 보는 확인, Windows 화면에서 사람이 눌러 보는 확인.
