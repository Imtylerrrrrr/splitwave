## 고친 것

- **모델 묶음이 릴리스마다 다시 받히던 문제.** v1.3.0 빌드에서 모델 묶음(약 51 MB) 안에 든 부가 캐시 파일 하나가 바뀌어, 스템 분리 버전 업데이트가 앱 본체(33 MB) 외에 모델까지 다시 받게 돼 있었어요. 이제 빌드에서 그 파일을 빼서 모델 묶음이 릴리스 사이에 그대로 유지돼요.
- 기능은 v1.3.0 과 같아요. v1.3.0 의 새 기능(빼고 듣기)은 [v1.3.0 노트](https://github.com/Imtylerrrrrr/splitwave/releases/tag/v1.3.0) 를 보세요.

## 업데이트 크기 (허브 사용 시)

| 앱 | 받는 크기 |
|---|---|
| Splitwave | 약 27 MB |
| Splitwave + 스템 분리 | 이번 한 번은 약 84 MB (앱 본체 33 MB + 모델 51 MB). 다음 릴리스부터는 앱 본체만 |
| Tempo Follow (실험) | 약 32 MB |

허브 자체는 바뀌지 않았어요. 허브를 열고 `업데이트` 를 누르면 돼요. 처음이면 `splitwave-hub.exe` 하나만 받으세요.

## 확인한 것과 못 한 것

- 확인: v1.2.1 과 v1.3.0 의 모델 묶음을 내려받아 비교해 달라진 파일이 `.agent_harnesses.json` 하나뿐임을 확인. 빌드 정리 단계가 그 파일을 지우는지 테스트.
- 못 함: 실제 Windows 화면에서 사람이 눌러 보는 확인.
