## 고친 것

- **허브 화면이 비어 보이던 문제.** v1.2.0 을 게시한 뒤 v1.1.0 허브를 열면 앱 목록이 하나도 안 나왔어요. "허브 새 버전" 안내 줄을 화면에 넣는 코드의 오류였어요.
  - 이미 받은 허브는 지금 그대로 다시 열면 목록이 나와요. 따로 받을 것은 없어요.
  - 이 버전의 허브는 안내 줄이 떠도 목록이 정상으로 나와요.

## 알아 둘 것

- v1.1.0, v1.2.0 허브는 앱 설치와 업데이트는 계속 되지만, 허브 자체 업데이트 안내는 뜨지 않아요. 새 허브를 쓰려면 이 페이지에서 `splitwave-hub.exe` 를 다시 받으세요.
- 앱(Splitwave, 스템 분리, Tempo Follow)의 기능은 v1.2.0 과 같아요.

## 확인한 것과 못 한 것

- 확인: v1.1.0 허브의 화면 코드로 문제를 재현했고, 허브 항목을 뺀 매니페스트에서는 앱 카드 3개가 그려짐. 고친 허브는 안내 줄과 카드가 함께 그려지는 것을 테스트로 확인.
- 못 함: 실제 Windows 화면에서 사람이 눌러 보는 확인, 허브 자체 업데이트 버튼.
